Для работы (и запуска) приложения необходимо скачать только exe-файл.  

Файл Snake.py демонстрирует рабочий код приложения, который можно запустить в компиляторах без сторонних библиотек (но вместе с файлом подсчёта рекорда очков).

В ветке "test" находится версия приложения с интегрированным встроенным модулем Python "unittest".
